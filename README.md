# Lyric Typing

Game mengetik lirik dengan tampilan neon modern, cocok untuk latihan kecepatan mengetik sambil menikmati lagu favorit.

## Deskripsi

Lyric Typing adalah aplikasi web single-page yang menghadirkan pengalaman typing game berbasis lirik. Pengguna dapat:

- memilih level kesulitan
- menempelkan teks lirik secara manual atau upload file
- memainkan mode typing dengan visualisasi musik dan progress bar
- menikmati tampilan antarmuka futuristic dengan tema neon

## Fitur

- Antarmuka modern dan responsif
- Mode game typing berbasis lirik
- Pilihan level permainan
- Input lirik dari teks manual atau file
- Tampilan skor, progress, dan status permainan
- Desain UI bergaya cyber / neon

## Screenshot

- HTML5

## Cara Menjalankan

1. Clone repository ini
2. Buka file `index.html` di browser, atau jalankan server statis lokal jika diinginkan
3. Mulai permainan dan masukkan lirik yang ingin dimainkan

Contoh menggunakan Python:

```bash
python -m http.server 8000
```

Lalu buka:

```text
http://localhost:8000
```
